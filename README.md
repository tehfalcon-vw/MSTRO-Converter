<h1 align="center">MSTRO Converter</h1>

<p align="center">A simple desktop utility for converting between MSTRO and BIN files.</p>

## Features

- Convert MSTRO files to BIN files.
- Convert edited BIN files back to MSTRO using a matching template.
- Repair supported MED9 checksums automatically.
- Available for Windows and macOS.

## Usage

1. Choose **Convert to BIN** or **Convert to MSTRO**.
2. Select the required input files and output location.
3. Start the conversion.

## Supported files

The current checksum profile supports the verified 2 MiB MED9.1 file layout.
Always keep an original backup and a known-good recovery path.
